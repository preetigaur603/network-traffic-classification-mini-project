# Network Traffic Classification - Mini Project

This mini project involves building a Machine Learning model to classify network traffic. It helps in identifying malicious or abnormal patterns that could be used for network security or optimization.

## 📁 Project Structure
- `dataset/` - contains the CSV files used for training and testing.
- `model/` - saved trained model files.
- `app.py` - main Flask application file.
- `templates/` - HTML templates for the web interface.
- `static/` - CSS and JS files for the frontend.

## ⚙️ Technologies Used
- Python
- Scikit-learn
- Flask
- Pandas, NumPy, Matplotlib

## 🚀 How to Run
```bash
pip install -r requirements.txt
python app.py

Features
Upload custom datasets

Train different ML models (SVM, Random Forest, etc.)

View accuracy, confusion matrix, and top features

Web-based UI with graphs and tables
